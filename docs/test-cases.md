## Execution notes

- **Isolation:** every API case receives a fresh app and database; every E2E case
  creates its own account pair through `POST /api/accounts`.
- **Determinism:** idempotency keys are timestamp + UUID; no test relies on a prior
  test's mutation. The dashboard case does not assert exact seed balances because a
  developer may reuse a running server, but it does assert the seeded cards and
  currency-formatted balances.
- **Evidence:** Playwright HTML, JUnit, screenshots, videos and traces; node:test
  console output; k6 JSON summary.
- **Traceability:** requirement IDs are mapped in
  [`requirements-traceability-matrix.md`](requirements-traceability-matrix.md).
- **Manual cases:** responsive and accessibility checks are exploratory and are not
  claimed as automated coverage.
